# 版本记录

## 0.1.0 · 2026-10-23

补充 `attendance/` 应用：人体框按座位区域筛选，滚动窗口取人数中位数；浏览器导入CSV名单、逐项确认并保存SQLite记录，支持课程查询与CSV导出。新增自动检查和示例配置。示例名单与测试检测框均为合成输入。

这批应用代码在本次公开整理中新增，与原项目2026年4—5月的相机、人脸检测及模型部署经历分别记录。当前Windows验证覆盖业务与HTTP流程，未接入树莓派、摄像头或人体模型进行实测。

原有 `src/pi5/` 三份脚本保持原始字节；源码文件、来源及SHA256见 [source-manifest.json](../source-manifest.json)。它们分别提供相机操作、SCRFD人脸检测和独立蜂鸣器控制。
