# 架构与版本

采集层由树莓派5、CSI摄像头、Picamera2/libcamera和显示设备组成。推理层按具体分支加载模型，处理缩放、归一化、输出解码、NMS和坐标还原。课堂流程层筛选学生座位区域、显示人数与时间；记录层由教师对照名单确认后保存结果。

公开`face_detect.py`为SCRFD NCNN人脸检测分支；YOLO11人脸训练、轻量化/量化与课堂YOLO11n人体计数为不同阶段或用途，不把公开分支等同于所有最终功能源码。`camera_display.py`仍保留早期IMX219窗口名称，源文件按原始快照保留。

课堂过程是“人数核验—教师确认—保存记录”。不能由人体或人脸框直接推断具体学生身份。对只需人数与最终人工状态的使用方式，可以控制图像保留；这是一项数据保留选择，不据此称所有版本已经自动删除图像。
