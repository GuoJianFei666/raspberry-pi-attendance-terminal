# 数据与模型版本

| 版本或材料 | 对应用途 | 本仓库内容 |
| --- | --- | --- |
| YOLO11单类face训练 | 图片/标签配对清理与人脸检测训练 | 历史经历说明，训练集与权重不分发 |
| MobileNetV4、BiFormer、NCNN / INT8 | 历史人脸模型改进与树莓派部署 | 项目工作说明，与新增人体应用分别记录 |
| SCRFD / NCNN | 人脸框与五点定位，相机/本地图片对照 | 原有 `src/pi5/face_detect.py` |
| 课堂人体计数与名单服务 | 座位区域人数、教师确认及记录保存 | 本次新增 `attendance/` |

历史face数据快照为train 13,386张、41,547个框，val 3,347张、10,299个框，合计16,733张、51,846个face框。该统计是本地训练材料的静态检查，不对应新增人体模型的精度或本仓库公开数据量。

[WIDER FACE标注复核](DATA-INSPECTION.md)记录另一份公开标注的统计：train/val为12,880/3,226张图像、159,420/39,708行人脸框，invalid=1为2,399/585行。两份统计对应不同材料，分别保留来源、版本和口径。

早期YOLO导出元数据包含640×640输入、batch=1、80个数字类别与half=false，不能据此认定为最终单类face、INT8或课堂人体模型。新增应用校验所选类别名称，要求明确的人体类别。

真实课堂图像、学生名单、私人报告、训练集与模型权重不在仓库中。示例名单与自动检查数据为合成输入；设备适配器尚需在配置好的树莓派与人体模型上验证。
