# 数据与分支口径

| 分支/材料 | 可说明的内容 |
| --- | --- |
| YOLO11 face训练配置 | 单类face训练及数据清洗经历 |
| MobileNetV4/BiFormer与NCNN/INT8 | 个人项目中的模型改进与部署工作 |
| 公开SCRFD NCNN脚本 | 采集、推理前后处理、相机/本地图片对照 |
| 课堂YOLO11n人体计数 | 学生区域可见人数与教师核对名单流程 |

已读face数据快照为16,733张图片、51,846个标注框；该统计不对应课堂人体计数模型精度。模型输入尺寸、类别元数据和公开脚本的模型版本各自保留，不将不同快照拼为同一个训练产物。

本次发布不包含真实课堂图像、学生名单、私人报告、训练集或模型权重；不新报速度、准确率、部署数量或节省时间。
